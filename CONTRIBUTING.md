# Contributing

Thanks for helping improve Trickcal Tools Clone.

## Pull Requests

- Keep changes focused and avoid unrelated refactors.
- Include tests when planner logic, storage behavior, data mapping, or user-facing behavior changes.
- Update `CHANGELOG.md` for user-visible changes.

## 開発と品質確認

作業前に [AGENTS.md](AGENTS.md) と [findings.md](findings.md) を全文読み、Bunのコマンド、ソース配置、データ更新と品質確認の条件を適用してください。更新・復旧は [how-to-update.md](how-to-update.md)、検証記録は [verification.md](verification.md) を参照してください。
